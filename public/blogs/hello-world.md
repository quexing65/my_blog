# Hello World

This is a sample blog post template. You can use this as a starting point for your own blog posts.

## Getting Started

To create a new blog post, create a new markdown file in the `public/blogs` directory with the following frontmatter:

```yaml
---
title: Your Post Title
date: YYYY-MM-DD
description: A brief description of your post.
tags:
  - tag1
  - tag2
---
```

## Writing Content

After the frontmatter, you can write your content using standard markdown syntax:

- **Bold text**
- *Italic text*
- [Links](https://example.com)
- Lists
- Code blocks
- And more!

## Images

To add images to your blog post, place them in the same directory as your markdown file and reference them like this:

```markdown
![Alt text](image.png)
```

## Conclusion

Happy blogging!
