# Cloudflare Pages 部署说明
YYsuni/2025-blog-public 项目支持 Cloudflare Pages 部署，项目中已包含：
- `open-next.config.ts` - OpenNext 配置
- `wrangler.toml` - Wrangler 配置
- 构建命令：`npm run build:cf`
- 部署命令：`npm run deploy`
